# ptavideo

Минимальная страница для публикации одного видео на GitHub Pages.

## Публикация

1. Создайте репозиторий `ptavideo` в аккаунте `aonass`.
2. Добавьте этот локальный репозиторий как remote и отправьте ветку `main`.
3. В GitHub откройте **Settings → Pages**.
4. Выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`.

После публикации страница будет доступна по адресу:

<https://aonass.github.io/ptavideo/>
